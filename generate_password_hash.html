🔐 Password Hash Generator

Use this tool to generate a SHA-256 hash of your password. Copy the hash and update the PASSWORD_HASH variable in index.html.
Steps to update your password:
1. Enter your desired password above
2. Click "Generate Hash"
3. Copy the hash below
4. Open index.html and find the line: const PASSWORD_HASH = "...";
5. Replace the hash value with your new hash
6. Commit and push the changes
